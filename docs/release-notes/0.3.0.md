# P4V Patch 0.3.0

支持 Windows x64、P4V 2026.2 / Qt 6.8.6。

## 新功能与改进

- **Submit Changelist 支持 AI 生成提交描述**：在 `Submit Changelist` 窗口的 `Write a changelist description` 右侧新增 **AI Generate** 按钮，点击后切换为 `Generating...` 并显示旋转等待动画。
- **自动收集 Changelist Diff 并调用 Codex CLI**：后台异步通过 `p4.exe` 获取当前 Changelist 已勾选文件的变更与统一 diff（若无已打开文件且为编号 Changelist，则回退读取 shelved diff），通过本地 `codex exec` 生成简洁的中文提交描述并覆盖写入 `description` 文本框。
- **Preferences → Patch 新增 Codex 模型设置**：在 `Edit → Preferences → Patch` 中新增 **Codex** 设置分组，通过本地 Codex CLI 的 `app-server` `model/list` 接口异步拉取可用模型列表（支持点击 `Refresh` 刷新），默认选中 `luna` 模型（如 `gpt-5.6-luna`），配置独立保存于 `~/.p4qt/p4vpatch.ini` 的 `Codex/Model`。

## 安装与更新

下载 `p4vpatch-v0.3.0-windows-x64.zip`，保存工作并退出 P4V 和 Launcher，将 ZIP 中的 `p4vpatch-launcher.exe` 与 `p4vpatch.dll` 一起放入 `p4v.exe` 所在目录，再通过 Launcher 启动。已安装 0.1.0 及以上版本 Launcher 的用户也可直接在欢迎页点击“更新补丁”在线更新 `p4vpatch.dll`。不包含 Qt/P4V 运行时，不覆盖其文件。

若 P4VC 后台服务阻止 DLL 更新，确认没有需要保留的窗口/任务后，可用 `p4v.exe -p4vc shutdown` 正常关闭服务。

## 验证与限制

- 新增离线测试与实机验证覆盖 `Submit Changelist` 标题解析、模型列表拉取与默认 `luna` 模型选择、配置持久化、`AI Generate` 按钮布局与旋转等待动画、已勾选文件 diff 传递、生成结果覆盖及错误回退。
- AI 生成描述依赖本机已安装并完成登录配置的 Codex CLI，以及与 P4V 同目录或 PATH 中的 `p4.exe`。生成失败或超时不会覆盖原有的描述文本。
- 仍是针对特定 P4V/Qt 的非官方实验性补丁；首次使用请保存工作。P4V 升级后需重新验证登录、终端及 Changelist 窗口控件兼容性。
- 当前使用 HTTPS 和 Release 清单中的 SHA-256 校验，不强制发布者数字签名，请只使用可信仓库。

回退：退出 P4V 和 Launcher，恢复上一版完整 ZIP；仅回退 DLL 可恢复 `p4vpatch.dll.bak`。详见发布手册。
