# P4V Patch 0.2.0

支持 Windows x64、P4V 2026.2 / Qt 6.8.6。

## 新功能与改进

- Submitted Changelist 的只读 Description 支持 Jira 链接：识别 `[Jira]BR-339863`，将编号显示为带下划线的链接，点击通过系统默认浏览器打开 `https://jira.garena.com/browse/BR-339863`。支持多个编号和变长数字，不修改 Description 原文、HTML 或 Perforce 数据，不替换控件或改变布局。
- 保留原有 Markdown、已有链接、选字、复制及右键菜单；拖选或 Shift 选择不误打开 Jira。仅增强已核实的 Submitted Changelist 只读控件，不影响 Pending/Submit 编辑区域。
- Launcher 允许 P4V 多开：已有 P4V 窗口或 P4VC 后台服务不再阻止启动。补丁只注入本次新建的进程，不追溯注入已有实例。
- Launcher 的检查、启动、下载及安装错误以红字显示，覆盖主页面、详情和错误弹窗；适配浅色/深色及 P4V 皮肤，重试或恢复正常后还原颜色。
- 欢迎页保持进度条显隐时的布局占位，展开/收起详情保持顶部位置，减少视觉跳动。
- 保留更新 DLL 时的运行中保护，不自动结束 P4V；拦截说明包含进程 PID，并提示 P4VC 后台服务可能仍在运行。

## 安装与更新

下载 `p4vpatch-v0.2.0-windows-x64.zip`，保存工作并退出 P4V 和 Launcher，将 ZIP 中的 `p4vpatch-launcher.exe` 与 `p4vpatch.dll` 一起放入 `p4v.exe` 所在目录，再通过 Launcher 启动。不包含 Qt/P4V 运行时，不覆盖其文件。

**多开与红字提示属于 Launcher 更新，必须手动替换 ZIP 中的 EXE。** 在线“更新补丁”只替换 DLL，不会更新 Launcher。旧版 Launcher 仍可加载本版 DLL，因此更新清单最低 Launcher 版本保持 0.1.0。

若 P4VC 后台服务阻止 DLL 更新，确认没有需要保留的窗口/任务后，可用 `p4v.exe -p4vc shutdown` 正常关闭服务；不需要为普通多开启动关闭它。

## 验证与限制

- 新增离线回归覆盖 Jira 匹配、点击 URL、刷新、选字、原有链接、主题、文档更换、滚动、多开启动流程、红字与错误恢复；测试不连接 Perforce/Jira、不启动真实 P4V。
- 已在真实 P4V 2026.2 / Qt 6.8.6 的 Submitted Changelist 上验证 Jira 显示及悬停手型，源/显示文档与布局保持不变。实际访问 Jira 仍取决于网络和登录权限。
- 仍是针对特定 P4V/Qt 的非官方实验性补丁；首次使用请保存工作。P4V 升级后需重新验证登录、终端及 Description 控件兼容性。
- 新增 Jira 链接为显示层增强，不进入复制出的 HTML，也不新增原生“复制链接地址”菜单项；已有语法高亮器时保守跳过。
- 当前使用 HTTPS 和 Release 清单中的 SHA-256 校验，不强制发布者数字签名，请只使用可信仓库。

回退：退出 P4V 和 Launcher，恢复上一版完整 ZIP；仅回退 DLL 可恢复 `p4vpatch.dll.bak`。详见发布手册。
