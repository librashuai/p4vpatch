# P4V Patch 0.1.0

支持 Windows x64、P4V 2026.2 / Qt 6.8.6。

- Launcher 改为 Qt Widgets GUI，复用 P4V 附带运行时，不弹控制台。
- 界面跟随 P4V 的浅色/深色主题和 UI 字体；简化欢迎页，将路径与诊断收纳到“详情”，仅在有新版时显示更新说明。
- 欢迎页显示本地版本及 GitHub Release 说明；检测到新版必定显示，由用户手动决定是否更新。
- 补丁 DLL 更新支持大小、SHA-256、PE/版本与兼容性检查；禁止 P4V 运行时替换，保留 `.bak`。
- 添加统一 Windows 版本资源、发布打包及 GitHub 草稿/正式发布脚本。
- 保留自动登录、后台 ticket 续期和原生 Terminal 功能。

安装：下载 `p4vpatch-v0.1.0-windows-x64.zip`，退出 P4V，将 EXE/DLL 一起放入 `p4v.exe` 目录后运行 Launcher。不包含 Qt/P4V 文件。开发目录准备匹配的 Qt 运行时后，可指定外部 P4V 路径或在欢迎页选择 P4V；缺少 P4V 不再阻止打开欢迎页，补丁始终使用 Launcher 旁的 DLL。

这是针对特定 P4V/Qt 的非官方实验性补丁。首次使用请保存工作；升级后需重新验证登录和终端。Launcher 在线更新只替换补丁 DLL，自身更新需退出后手动替换完整 ZIP 内的两个文件。回退请关闭 P4V，恢复旧版 ZIP 或 `p4vpatch.dll.bak`。

安全：当前通过 HTTPS 和同一 Release 清单中的 SHA-256 校验文件，不强制验证发布者数字签名，请仅使用可信仓库发布的文件。详见仓库发布手册。
